<p>代理怎么设，取决于你在哪儿用它。同一份订阅，可能只在书房的台式机上开，也可能电脑加手机一起用，还有人把出口做在路由器上让全屋设备共享。四种场景的配置位置完全不同，要遵守的原则却只有一条：付款前后那段时间，出口地址不要变。下面按场景给出落点、验证命令和容易踩的坑，最后说明为什么这条原则比选哪家线路更重要。</p>

<h2>一、"支付前后一致"落在哪几个时间点</h2>
<p>这句话听着笼统，拆开是四个时刻。</p>
<h3>点开订阅页之前</h3>
<p>此时出口已经确定，中途不再切换。浏览器插件、系统代理、客户端软件三处同时开启时，容易出现流量走了不同路径的情况，先关掉多余的。</p>
<h3>扣款成功之后的两小时</h3>
<p>这段时间常有订阅状态同步、二次验证、邮箱确认等动作，出口保持一致能避免"付款成功但状态不同步"的尴尬。很多人付款后立刻关代理去干别的，问题就出在这里。</p>

<h2>二、场景一：只在一台电脑上操作</h2>
<p>最简单也最容易配错的场景。</p>
<h3>落点选浏览器插件还是系统代理</h3>
<p>只用一个浏览器，装 SwitchyOmega 之类的插件最干净，规则按域名分流，不影响系统其他流量。多浏览器共用则用系统代理更省事。</p>
<h3>验证出口的三条命令</h3>
<p>curl ipinfo.io/ip 看地址，curl ipinfo.io/country 看国家，mtr -c 50 目标域名 看丢包。三条都在终端跑，比在网页上看更可信，因为网页本身可能走了另一条路径。</p>
<h3>常见坑：DNS 没走代理</h3>
<p>系统代理通常只覆盖 HTTP 和 HTTPS，DNS 仍是本地解析。在浏览器设置里开启"使用安全 DNS"或走代理解析，否则 dnsleaktest.com 一测就露。</p>

<h2>三、场景二：电脑加手机两种设备</h2>
<p>两台设备最容易出现"地址在这边、会话在那边"的错位。</p>
<img src="/tp.png" alt="电脑与手机共用同一住宅出口的代理落点配置示意">
<h3>手机端怎么挂</h3>
<p>安卓可以直接在 WLAN 设置里填代理地址和端口；iOS 需要在 Wi-Fi 详情页配置 HTTP 代理，且部分应用不遵循系统代理，需要单独设置。两端用同一条出口，不要一边住宅一边机房。</p>
<h3>时区要各自跟随</h3>
<p>手机默认自动获取时区，如果出口在另一个时区而手机仍用本地时间，两边就差了几个小时。手动把设备时区改成出口所在时区，这个小动作能减少一类莫名其妙的环境异常。</p>
<h3>不要两台设备同时高频操作</h3>
<p>同一账号在两台设备上同时开工，会话会互相顶掉。日常用一台为主，另一台只做查看。</p>

<h2>四、场景三：家里路由器做成全局出口</h2>
<p>全屋共享看着方便，实际上要求最高。</p>
<h3>在哪一层做转发</h3>
<p>OpenWrt 类固件可以用透明代理插件，把指定设备或整个 LAN 的流量导向上游。关键是分流规则：只让需要走代理的设备走，不要把智能家居和电视一起带进去，那些设备的流量会拖慢线路。</p>
<h3>出口地址是否固定</h3>
<p>路由器上挂动态池，全家设备的表现会随着地址轮换一起变，包括你在用的那台电脑。家用场景建议用静态独享，一条地址长期不变，排查时变量最少。</p>
<h3>掉线后的重连</h3>
<p>在路由器上配置看门狗脚本，定时探测出口是否可达，连续三次失败后重启代理进程。没有这一步，半夜掉线可能到第二天早上才发现。</p>

<h2>五、场景四：团队成员异地接入同一条出口</h2>
<p>这种做法在家宽场景很常见，风险也最集中。</p>
<h3>先想清楚是共享还是分配</h3>
<p>同一条出口给多人用，等于让多个身份共享同一个网络历史。若这几个账号本就属于同一组织、用途单一，影响可控；若彼此独立，建议按人分配，哪怕成本翻倍。</p>
<h3>用网关收口，别让成员各配各的</h3>
<p>在一台内网网关上配置出口，成员通过 VPN 或跳板接入，出口由网关统一控制。这样地址不会因为某个人本地的网络环境而变化，排查时也只有一个入口。</p>
<h3>权限与日志一起做</h3>
<p>谁能用哪条出口、什么时候用的，要能查。没有日志，一旦出现异常只能靠回忆，而回忆通常指向错误的方向。</p>

<h2>常见问答</h2>
<h3>付款时能不能用手机热点？</h3>
<p>答：不建议在付款这个节点换网络。热点的出口地址与日常不同，会让登录地和付款地出现偏差。应急可以，事后回到原出口。</p>
<h3>代理软件和浏览器插件同时开会怎样？</h3>
<p>答：可能出现流量分流混乱，表现为网页能开但接口超时。排查时先只保留一层代理，确认出口地址唯一。</p>
<h3>路由器方案的延迟会不会更高？</h3>
<p>答：会略高，通常多几毫秒到十几毫秒，取决于路由器性能和加密方式。这个量级对网页对话影响很小。</p>
<h3>团队共用一条出口一定会出问题吗？</h3>
<p>答：不一定，取决于成员之间是否存在身份重叠。同一组织的正常协作与多个独立身份共用，风控含义完全不同。</p>

<h2>合规提示</h2>
<p>本文的配置方法用于个人或企业内部网络的正常访问管理。请勿将共享出口用于运营虚假账号、冒充他人身份或规避平台的地区服务限制。</p>
<p>在企业环境部署代理网关时，应遵守内部信息安全制度，对成员访问行为留痕并取得必要授权。跨境访问需符合数据出境的相关法规。</p>
